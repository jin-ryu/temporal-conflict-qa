# 시간 충돌에서의 근거 시점 유효성(Temporal Validity) — 연구 포지셔닝

## 1. 핵심 주장

- RAG에서 같은 사실의 **옛 버전과 새 버전이 함께 검색**되면, 최신 LLM조차 **틀린 시점의 근거를 인용**해 답한다.
- 그러나 **기존 평가지표는 이 오류를 구조적으로 포착하지 못한다.**
  - 정답률(EM)은 *최종 답*만 본다.
  - 근거 충실도(citation faithfulness)는 *시점*을 고려하지 않는다(옛 문서도 옛 답을 뒷받침하므로 "정상"으로 통과).
- 핵심 질문은 **"답이 맞았는가"가 아니라 "맞는 시점의 근거를 골랐는가"** 이다.

### 기여 (Contributions)

- **① 지표·프로토콜**: 근거의 **시점 유효성(Temporal Validity)** 을 측정하는 평가 축 — 표준 citation 평가(ALCE)의 *시간 인지적 확장*.
- **② 발견**: 최신 LLM이 두 표준 축(correctness·faithfulness)을 *통과하면서도* 시점 유효성에서 실패함을 **정량화** → 기존 지표의 구조적 맹점을 실증.
- **③ 자원**: 시점-유효 근거 라벨(어느 버전이 정답 근거인가)을 갖춘 평가셋(HoH 편집이력 기반).
- *(조건부)* 개선 방법론 — 파일럿 결과를 보고 결합 여부 결정.

---

## 2. 관련 키워드

| 키워드 | 설명 |
|---|---|
| **RAG** | LLM이 답하기 전에 외부 문서를 검색하여, 그 문서를 근거로 답을 생성하는 방식 |
| **근거(grounding)·인용(citation)** | 모델이 답의 근거가 된 문서를 표시하는 것. 현대 RAG는 답에 inline citation(예: "…답 [3].")으로 부착하며, 품질은 ALCE의 citation precision/recall로 평가 |
| **시간 충돌(temporal conflict)** | 같은 사실의 옛 버전과 새 버전이 검색 결과에 함께 포함되는 상황 |
| **정답률(EM/Accuracy)** | 모델의 최종 답이 정답과 일치하는지 |
| **근거 충실도(faithfulness)** | 인용 문서가 답을 실제로 뒷받침(함의)하는지, 또는 모델이 그 문서를 실제로 사용했는지 |

## 3. 문제 정의

### 3.1 선행연구가 보인 두 가지 사실

본 문제의식은 최근 두 연구에 근거한다.

**(1) 시간 충돌은 실제로 RAG 성능을 떨어뜨린다 — HoH (ACL 2025)**

- **실험 구성**: Wikipedia 스냅샷(2024.06–11)으로 구축한 RAG 벤치마크(QA 96,124 · 문서 219,463). 모델 Qwen-2.5-7B, Llama-3.1-8B/70B(검색기 BGE).
- **발견**: 현재 문서가 포함돼 있어도 outdated 문서가 끼면 성능 저하. *"outdated 문서가 있는 것이 관련 정보가 아예 없는 것보다 더 위험"* 하며, 모델이 확신에 찬 어조로 오답을 낸다.
- **한계(우리 빈칸)**: 답을 perfect/missing/harmful로 채점하고 검색 비율을 분석할 뿐, **모델이 시점상 유효한 문서를 근거로 삼았는지는 채점하지 않는다.**

**(2) 정답과 근거는 별개의 축이다 — Correctness is not Faithfulness (Wallat et al., SIGIR 2025)**

- **실험 구성**: Cohere Command-R+로 NaturalQuestions(위키 기반)의 인용 행동 분석(BM25 + ColBERT v2).
- **주장**: 인용이 *correct*(문서가 답을 뒷받침)여도 *faithful*(모델이 실제로 그 문서를 사용)하지 않을 수 있다. 사전 지식으로 답을 정한 뒤 일치 문서를 사후 인용하는 경우 **최대 57%**.
- **한계(우리 빈칸)**: 단일 사실만 다루며 **시간 충돌은 범위 밖**.

### 3.2 기존 지표가 포착하지 못하는 사각지대

- 정답률은 *최종 답*을, 근거 충실도는 *인용 문서가 답을 뒷받침하는지*를 평가한다.
- 시간 충돌에서는 이 둘이 **시점 오류를 놓친다.**

**예시 (본 평가셋)** — 질문: *"현재 글루코노락톤을 발효시키는 효모는?"* (정답 = 최신 = *Maudiozyma bulderi*)

- 컨텍스트: [문서 A · 2024-07 · 최신] *Maudiozyma bulderi* / [문서 B · 2024-06 · 옛] *Saccharomyces bulderi*
- 모델이 **"Saccharomyces bulderi [B]"** 로 답하면:

| 지표 | 판정 | 이유 |
|---|---|---|
| 정답률(EM) | ❌ | 옛 답이라 오답 — 단, *왜* 틀렸는지(시점 근거 오선택)는 알 수 없음 |
| 근거 충실도(citation precision) | ✅ **통과** | 문서 B가 그 옛 답을 *실제로 뒷받침*하므로 "근거 정확"으로 채점 |
| **시점 유효성(우리 지표)** | ❌ | 문서 B는 *옛 버전* → 틀린 시점 근거 |

- → **모델이 틀린 시점 근거를 댔는데도 충실도는 정상으로 판정**하며, *오류의 원인(시점 근거 선택 실패)이 어떤 기존 지표에도 드러나지 않는다.*

**가중 요인 — 사후 합리화(post-rationalization)** (Wallat 2025)

- 모델이 검색 문서를 실제 근거로 삼지 않고, 사전 지식으로 답을 먼저 정한 뒤 일치 문서를 나중에 인용하는 현상.
- 이 경우 답·인용이 맞아 보여도 *근거가 시점상 옳은지와 무관하게* 답이 결정된다.
- 고위험·감사 환경에서는 "답이 우연히 맞은 것"과 "올바른 시점 근거에서 도출된 것"을 구분해야 하므로, 정답률만으로는 근거 신뢰성을 보장할 수 없다.

→ 본 연구가 제안하는 것은 *더 엄격한 정답률*이 아니라, **정답률·충실도가 모두 놓치는 근거의 시점 차원**이다.

### 3.3 이 오류는 언제·얼마나 자주·왜 문제가 되는가

**(언제) 발생 상황**

- 같은 사실의 역사적 버전과 현재 버전이 코퍼스에 공존하고 질의가 시점에 민감할 때:
  - 법률 조문 개정 이력, 의료 가이드라인 개정, 소프트웨어 버전 문서, 위키형 진화 지식베이스 등.
- **예외가 아니라 일상**: HoH에 따르면 시간 가중(Gaussian decay)을 적용해도 검색 상위 5개에 outdated 문서가 포함될 확률이 **49.5%**(현재 문서 70.2%).

**(얼마나 자주) 빈도**

- *직접* 빈도(모델이 시점상 틀린 버전을 근거로 답하는 비율)는 **아직 측정된 바 없다** — 시점 유효성을 채점하는 지표가 없기 때문이며, *이 빈도의 규명이 본 연구의 핵심 기여*다.
- 인접 증거는 빈도가 결코 낮지 않음을 시사:
  - outdated 추가 시 harmful 출력 급증(HoH Table 5): Llama-70B 4.1→14.1%, Llama-8B 4.6→18.7%, Qwen-7B 3.5→19.9%.
  - outdated만 주어지면 harmful 출력 **71–83%**(HoH Table 14).
  - 충돌 *감지* 정확도조차 최고 **65.3%**(DRAGged, Gemini 2.5 Flash).
  - 일반적으로 인용의 최대 **57%**가 사후 합리화(Wallat 2025).
- → 충돌이 자주 검색되고(≈50%) · 자주 감지 실패하며(≈35%) · 근거가 자주 신뢰 불가(57%)인 조건이 중첩 → **시점-근거 오류도 빈번할 개연성이 높다.** 정확한 빈도는 본 연구가 측정.

**(왜) 결과**

- 이 오류는 **조용히** 발생한다 — 정답률·충실도를 통과하므로 자동 평가·인간 감사 모두 정상으로 오인.
- outdated는 "무정보보다 위험"(HoH) — 모델이 불확실성 대신 확신으로 답하기 때문.
- 웹검색이 제한되고 근거 감사가 필수인 고위험 영역에서 직접 피해:
  - **법률**: "2021년 체결 시점에 유효했던 조항은?" → 현행 조항 제시 시 법적 오판
  - **의료**: "2019년 가이드라인 기준 권장 용량은?" → 현행 가이드 제시 시 감사 오류
  - **금융**: "FY2020 기준 세율은?" → 현재 수치 제시 시 규정 위반
- 근거가 잘 달린 것처럼 보일수록 오히려 더 신뢰되어 위험이 가중된다.

### 3.4 빈칸

- HoH·Wallat 모두 "답"과 "근거"를 구분해야 한다는 지점까지 도달.
- 그러나 그 근거가 *질문 시점에 유효한 버전인지* 는 **어느 연구도 채점하지 않는다**(HoH는 답의 품질, Wallat은 인과적 사용 여부까지).
- **이 빈칸이 본 연구의 자리이다.**

## 4. Framing — 제3의 평가 축

현대 RAG는 답의 근거를 inline citation으로 부착하고, 그 품질을 두 축으로 평가한다. 본 연구는 이 둘로 환원되지 않는 **제3의 축**을 더한다.

| 축 | 질문 | 출처 |
|---|---|---|
| ① **Citation Correctness** | 인용 문서가 답을 뒷받침(함의)하는가? | 분야 표준 (ALCE citation precision/recall) |
| ② **Citation Faithfulness** | 모델이 그 문서를 실제로 사용했는가(사후 인용 아님)? | Wallat 2025 |
| ③ **Temporal Validity (신규)** | 인용한 근거가 *질문 시점에 유효한 버전*인가? | 본 연구 |

- **직교성**: §3.2 예시처럼 시간 충돌에서는 ①✅ + ②✅ 이면서 ③❌ 이 성립한다(옛 문서가 옛 답을 함의하므로 ①·② 통과).
- 따라서 ③ 시점 유효성은 기존 두 축의 **시간 인지적 확장**이며 독립적 평가 축이다.

### 4.1 TV는 정답률(EM)과 같은 것인가? — 아니다 (예상 질문)

- **무충돌에선 세 신호가 붕괴**: [정답 문서] = [시점-유효 문서] = [답을 함의하는 문서]가 일치 → EM·Correctness·TV 구분 불가(기존 연구가 혼용). **시간 충돌이 이 셋을 분리한다.**
- **TV의 대조군은 EM이 아니라 표준 Citation Correctness**: 충돌에서는 *틀린 시점 답*도 *그 시점 문서가 함의*하므로 citation precision이 통과한다(거짓 신뢰 신호). TV가 이를 교정한다.
- **TV는 EM의 분해**: EM은 "틀렸다"만 알려주지만, TV는 "*시점 근거를 잘못 인용해* 틀렸다"를 환각·distractor와 구분해 귀속한다.
- **EM↔TV 불일치 사례**(답 맞는데 옛 문서 인용 / 답 틀린데 현재 문서 인용)는 근거가 답과 따로 논다는 직접 증거다.
- → 기여는 "TV가 더 나은 정답률"이 아니라 **"표준 citation precision이 시점에 맹목임을 드러내고, 시간 인지적 근거 지표가 필요함을 보이는 것"** 이다.

### 4.2 인용이 정말 모델이 쓴 근거인가? (측정상 유의점)

- inline self-citation은 *선언된* 근거이지 인과의 보장이 아니다(ALCE도 한계를 지적; 사후 합리화 가능 — §3.2).
- → 실험에서는 선언 인용과 *행동 기준*(문서를 빼고 넣어 답의 변화 관찰)을 함께 측정해 이를 보완한다(파일럿 §5.2).

> 측정 지표·프로토콜과 개선 방법론의 구체화는 파일럿 결과로 확정한다. 본 문서는 framing까지를 다룬다.

│      ├─ 일반 도메인 …… HoH (ACL 2025)
│      ├─ 의료 ………… TempoMed (2026)

| **D. 평가 지표** | ALCE / CiteEval (2506.01829, ACL'25) / CiteBench | inline citation precision·recall(NLI/원리 기반) | 미채점 (시간 무관) | 표준 근거 평가 — 우리의 foil |
| | **Correctness ≠ Faithfulness** (Wallat, SIGIR'25, 2412.18004) | correctness vs faithfulness(인과적 사용) 구분. 사후합리화 57% | 미채점 (시간 무관, 충돌 없음) | faithfulness 축의 선행 |
| | **GaRAGe** (ACL'25 Findings, 2506.07671) | **gold grounding 주석에 up-to-date/outdated 라벨. 모델이 *관련·최신* 근거를 골랐는지 측정(RAF). 모델이 outdated 근거 사용함을 실증** | **부분 채점 (relevance에 시간 포함, 단 freshness 방향)** | **가장 가까운 경쟁자.** 빈틈 → ① freshness만(현재=정답, **as-of-past 미포함**) ② 실제 웹(통제 충돌 아님) ③ "표준 precision이 시점에 맹목"의 명시적 입증 없음 |

### 5.3 빈칸과 본 연구의 위치 (정직한 평가)

- **시간 인지적 grounding 평가라는 큰 우산은 이미 점유됨.** 가장 가까운 **GaRAGe(Findings of ACL 2025, 2506.07671)** 는 gold 주석에 outdated/up-to-date를 포함하고, 모델이 *최신·관련* 근거를 골랐는지(RAF) 측정하며, 모델이 outdated 근거를 쓴다는 것을 실증했다.
- **GaRAGe가 남긴 잔여 차별점 (본문 확인 완료):**
  - **as-of-past 미포함**: GaRAGe는 freshness 전용 — Fast/Slow/Static은 *정보 최신성* 분류일 뿐 "과거 상태를 묻는" 질문이 아니며, OUTDATED 청크는 *항상* 틀린 근거로 취급하고 "현재 시각=정답"을 가정한다. *질문이 과거 시점을 겨냥해 outdated가 정답 근거가 되는* 경우는 다루지 않음.
  - **통제 충돌 부재**: 실제 웹 검색이라 "같은 사실의 현재·과거 버전 공존"을 격리하지 못함 — 우리는 편집이력으로 통제.
  - **표준 지표 맹목의 명시적 입증 부재**: RAF라는 *자체 지표*로 보일 뿐, "ALCE식 citation precision이 *틀린 시점 인용을 통과시킨다*"를 분리해 demonstration하지 않음.

- **점유 현황 (discovery × solution)** — freshness는 양쪽 모두 점유, **as-of-past만 얇음**:

| | discovery (평가·진단) | solution (방법) |
|---|---|---|
| **freshness** (현재=정답) | GaRAGe ✅ | T-GRAG · VersionRAG · CTRL-RAG ✅ |
| **as-of-past** (과거=정답 근거) | ❓ 비어 있음 | Can LLMs Time Travel? △ (법률 한정, GRPO) |

- **정직한 결론**: "시간 인지적 grounding"은 freshness 방향에서 평가·방법 모두 점유됨. **양쪽 다 얇은 유일한 칸 = as-of-past.** 단 (a) as-of-past는 *현실 중요성*에 의문이 남는 축이고, (b) solution 쪽도 Time-Travel이 부분 점유(법률·GRPO)다. → 방어선이 좁으며, **빠른 실행 + 날카로운 framing(일반/닫힌 코퍼스 + 통제 격리 + 맹목 입증)** 을 요구한다. 진행 여부는 *as-of-past 통제 파일럿*의 실측으로 판정한다.

### 5.4 리스크 및 기대 수준

- **영역 포화**: 위 연구 다수가 2025–2026 preprint, 빠르게 수렴 중 → **신속한 실행 필수.**
- **차별화 framing이 생사**: "충돌·근거 연구 + 시간"이 아니라 **"기존 지표가 못 잡는 제3의 축"** 으로 위치시켜야 함.
- **기대 venue**: 측정·발견(새 지표·벤치)만으로도 정식 논문(대체로 **Findings**). 개선 방법론 결합 시 **메인 도전** 가능. 탑티어 메인 보장은 아님.
- **데이터 한계**: 위키 편집이력은 통제된 측정 도구로 충분하나 충돌이 동질적(동일 문서 편집) → 본 논문에서 다출처 현실 충돌/고위험 도메인 슬라이스로 외부 타당성 보강 필요.
