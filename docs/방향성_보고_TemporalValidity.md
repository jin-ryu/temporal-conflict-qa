# Temporal Validity in RAG — 방향성 보고 (파일럿)

> **한 줄 요지**: RAG 검색결과에 *같은 사실의 옛/새 버전*이 섞여 있을 때, 모델이 **"과거 시점 질문"에 그 시점에 유효한 문서를 인용·사용하는가?** — 그리고 **표준 인용지표(ALCE/CitePrec)는 이 시점 오류를 구조적으로 못 본다.**

작성일: 2026-06-24 · 파일럿(n=48, blackbox 1종) 기준

---

## 1) 데이터셋 구축 방법

**원천**: HoH (Wikipedia 편집 이력 기반) — 같은 문서의 *옛/새 버전*이 한 검색 컨텍스트에 공존하는 **시간충돌**을 제공.

**파이프라인** (LLM 생성 없이 결정론적 + 사람/LLM 검수):
```
HoH 원본
 → ① 현실적 RAG 청크화 (원문 위키를 슬라이딩 윈도우로 분할; 옛/새 + distractor)
 → ② 무결성 정제(자동·결정론적)
       · 단일전환만(편집전쟁 churn 제거)  · 답↔근거청크 정확매칭
       · 엄격 근거게이트(답이 자기 청크에 실재)  · 수치/측정값 답 제거
 → ③ 구성 정제(genuine만)
       · "2024에 *진짜* 변한 것"(직책·소속·개명) vs "정적사실 정정"(고대사·신화·출생지) 분리
       · 후자는 *과거 유효답이 없어* 채점 오염 → 제거
 → 충돌 평가셋
```

**평가 항목 구조** (항목당):
- 질문에 **명시적 시점** 부여: *"As of {월 년}, …"* (LLM 생성 아닌 템플릿).
- **3조건**으로 제시: `conflict`(옛+새+distractor) / `current_only`(새만) / `outdated_only`(옛만) → *반사실(행동)* 측정용.
- **시점-유효 문서**를 `evidence_chunk_id`로 라벨.

**수율** (현재 1개 샤드 = 원본 600개 기준):
| 단계 | 잔존 | 비고 |
|---|---|---|
| 원본 | 599 | |
| ② 무결성 후 | 152 | 숫자·퍼센트·정정류 다수 제거(정상) |
| ③ genuine 후 | **58** | 깨끗한 시간변화만 |

→ 본실험은 샤드 추가(수율 ~10%) 또는 Wikidata 시간한정 사실(genuine 구성상 보장)로 **수백 규모 확장 가능**.

## 2) 문제 제기

**기존 RAG 인용평가(ALCE의 CitePrec)는 *시점*을 보지 않는다.**
- CitePrec = *"인용한 문서가 답을 뒷받침하나"* → **시점 무관**. 옛/새 어느 쪽이든 답만 받쳐주면 통과.
- 따라서 모델이 **과거 시점 질문에 *최신* 문서를 인용**해도 (시점은 틀렸지만) CitePrec은 **정상으로 통과** → **맹점**.

**신규 지표** (시점 분리):
| 지표 | 정의 |
|---|---|
| **TV_cite** | 모델이 *시점-유효* 문서(evidence_chunk_id)를 인용했나 |
| **TV_behav** | 모델 답이 *행동상* 어느 시점 문서에 좌우되나(3조건 반사실) |
| CitePrec (foil) | 인용문서가 답을 뒷받침하나 (시점 무관, 기존 표준) |

**핵심 그림 — ★ 2×2 맹점 셀**
| | CitePrec=PASS | CitePrec=FAIL |
|---|---|---|
| TV=PASS (맞는 시점 인용) | 이상적 | — |
| **TV=FAIL (틀린 시점 인용)** | **★ 맹점** | 양쪽 다 잡음 |

→ **★ 칸이 크면**: "틀린 시점 문서를 인용했는데 표준지표는 정상이라 판정" = *기존 평가의 사각지대*가 실재.

## 3) 현황 — Blackbox vs Open LLM

### Blackbox: Gemini 3.1 Pro (실측, n=48 as-of-past)

| 지표 | **as-of-past** (주력) | current (대조군, n=10) |
|---|---|---|
| **wrong-time 인용율** | **0.354** | 0.100 |
| TV_cite | 0.646 | 0.900 |
| TV_behav | 0.738 | 0.900 |
| EM | 0.583 | 0.900 |

**2×2 (as-of-past)**
```
                  CitePrec=PASS   CitePrec=FAIL
  TV=PASS(맞시점)       31              0
  TV=FAIL(틀시점)       14 ★            3
```
- **★ 맹점 = 14/48 = 29%**
- **틀린시점 인용의 82%(14/17)가 CitePrec엔 "정상"으로 보임.**
- 실패가 **과거질문에 특정**됨(현재 질문은 10%로 잘함) → *랜덤 노이즈가 아니라 진짜 시간 grounding 실패*.
- 17건 전수 육안검증: 15건이 *교과서적* 실패(과거질문에 새 답+최신문서 인용), 2건은 출력잘림 아티팩트.

> 채점 주: ★는 **유료 LLM judge 없이** 결정론적 포함검사(ALCE의 NLI 방식과 동치, 답이 짧은 엔티티)로 산출 — **재현 가능·무비용**.

### Open LLM: Qwen3-35B, Gemma (측정 예정)
- **평가셋·파이프라인 동일하게 준비 완료** — vLLM 서빙만 띄우면 즉시 측정.
- *가설*: 오픈/소형 모델은 프론티어보다 **시간 맹점이 같거나 더 큼** → 주장 강화 + **모델-불문 해결법**의 동기.
- (생성자가 Llama-3.1-70B라 자가생성 편향 회피 위해 **Llama 계열은 테스트에서 제외**.)
