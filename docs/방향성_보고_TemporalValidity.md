# Temporal Validity in RAG — 방향성 보고 (파일럿)

> **핵심 한 줄**: RAG에 *같은 사실의 옛/새 버전*이 섞이면 모델의 시점 grounding이 무너지는데(틀린 시점 문서를 인용·사용), **표준 인용평가(ALCE/CitePrec)는 그 오류를 *정상*이라 판정한다 — 구조적 맹점(★).** 우리는 이를 *측정*하고 *해결*한다.

작성: 2026-06-25 · 파일럿(n=48 as-of-past, blackbox 2종) 기준

---

## 1. 핵심 주장 (★ — 이게 논문의 심장)

표준 RAG 인용평가 **CitePrec**(ALCE식) = *"인용한 문서가 답을 뒷받침하나"* → **시점을 안 본다.**
따라서 모델이 **과거 시점 질문에 *최신* 문서를 인용**해도, (시점은 틀렸지만 답은 그 문서가 받쳐주므로) **CitePrec은 통과**시킨다.

> **충돌이 생기면 — 진짜 시점유효성(TV)은 *떨어지는데*, 표준 인용평가(CitePrec)는 *안 떨어진다*(만점 유지). 표준 지표가 *못 떨어지는 게* 문제다 = ★ 맹점.**

| 충돌 시 | 우리 지표 **TV_cite** | 표준 **CitePrec** |
|---|---|---|
| 값(Gemini/GPT) | **하락** 0.67 / 0.88 | **유지** 0.98 / 1.00 |
| 의미 | 시점 grounding 실패 | *그 실패를 못 봄* ★ |

**신규 지표**: `TV_cite`(시점-유효 문서를 인용했나), `TV_behav`(답이 행동상 어느 시점에 좌우되나). foil = `CitePrec`.

---

## 2. HoH(ACL 2025)와의 차별점 — 반드시 못박을 것

| | **HoH** (선행연구) | **우리** (novel) |
|---|---|---|
| 옛 정보의 지위 | **오염원**(현재 질문, 옛=오답, 무시 대상) | **시점-유효 정답**(as-of-past, 옛=정답, 지켜야 할 것) |
| 무엇을 잰다 | *답 정확도* 하락 | **인용-수준 시점유효성(TV) + 표준 인용평가의 맹점(★)** |
| 해결 | 벤치마크/진단 | (목표) 시점-grounding **해결법** |

→ HoH는 *"충돌이 답 정확도를 떨어뜨린다"* 까지. **HoH가 *안 한* 것 = "표준 *인용평가*가 틀린 시점 인용을 정상으로 통과시킨다(★)" + as-of-past 방향.** 여기가 우리 자리.

---

## 3. 측정 결과 (blackbox 2종, as-of-past n=48, 무료 결정론 채점)

### 3-1. ★ 2×2 맹점
```
              Gemini 3.1 Pro              GPT-5.5
          CitePrec=P  CitePrec=F     CitePrec=P  CitePrec=F
TV=PASS       32          0             42          0
TV=FAIL       15 ★        1              6 ★        0
```
- ★ 맹점 = **Gemini 15/48(31%) · GPT 6/48(12.5%)**
- **틀린시점 인용 중 표준평가 비가시율 = Gemini 94% · GPT 100%** ← *틀려도 CitePrec은 다 통과*

### 3-2. 충돌이 *유발한* 실패 (충돌 유무 대조 = 인과 isolation)
| 모델 | 옛문서만(충돌X) | 충돌(옛+새) | **낙폭** | 새문서만(바닥) |
|---|---|---|---|---|
| Gemini | 85.4% | 66.7% | **−18.8%p** | 0% |
| GPT-5.5 | 93.8% | 87.5% | **−6.2%p** | 4.2% |
> 모델은 *시점-유효 문서만 주면 잘 맞춘다*(85~94%) → **무능 아님.** 새 문서가 *끼는 순간* 떨어진다 → **충돌이 *멀쩡한 모델을* 망가뜨린다.** 이 낙폭이 *순수 충돌 효과*이고, 전부 CitePrec엔 비가시.

### 3-3. 대조군 (현재 시점이 정답)
current 질문 wrong-time = **0.10**(Gemini) → 실패가 *과거질문에 특정*됨 = recency-bias성 시간 grounding 실패(랜덤 노이즈 아님).

### 정리 표
| 지표 | Gemini | GPT-5.5 |
|---|---|---|
| wrong-time 인용율 | 0.333 | 0.125 |
| TV_cite | 0.667 | 0.875 |
| CitePrec(foil) | 0.979 | 1.000 |
| TV_behav | 0.738 | 0.884 |
| ★ 맹점 | 15/48 | 6/48 |
| 비가시율 | 94% | 100% |

## 4. 데이터셋 구축 (간략)

HoH 원본 → ① 현실적 RAG 청크 → ② 무결성 정제(단일전환·근거매칭·수치답 제거) → ③ 구성 정제(*genuine 시간변화* vs *정적사실 정정* 분리, 후자 제거) → **genuine 58**. 항목당 3조건(conflict/current_only/outdated_only) + 시점-유효 문서 라벨. *질문은 템플릿(LLM 생성 아님), 채점은 무료 결정론(ALCE NLI 근사).*

## 5. 정직한 현재 위치 & 다음 단계

**현 위치**: ★ 맹점 + 충돌-인과 isolation은 깨끗이 확인됨(blackbox 2종). 단 —
- 프론티어는 *부분적으로 robust* (GPT 낙폭 6%p) → 해결 헤드룸이 얇음.
- HoH와 겹치는 "충돌 낙폭"은 *조연*, **★ 인용평가 맹점이 주연**이어야 차별.
- n=48 파일럿, 해결법 미구현.

**탑티어(main) 판정(정직)**: *지금 그대로 = Findings급.* main까지는 **(①해결법의 일반성 + ②모델·조건 폭) 중 최소 둘**이 필요. ★ 관찰 단독은 동기부여 finding이지 완성 논문 아님.

**다음 (우선순위)**
1. **Open 모델 파일럿** — 낙폭·★가 *배포되는 모델*에서 커지나(= 해결의 무대). [무료, 다음 절 추천]
2. **해결법 프로토타입** — 충돌 하에서 "옛문서만 수준" 회복 (시점-유효구간 grounding).
3. 데이터 수백 확장 + 어려운 조건(distractor↑·sharp↑·격차↑).
4. 프레임을 *"temporal"→"RAG attribution 평가의 근본 맹점"* 으로 확장(천장↑).

**교수님께**: *"★(표준 인용평가가 틀린 시점 인용을 통과시킴)이 핵심 novelty, HoH와 차별. main까지는 해결법+폭 필요한 go/no-go 파일럿"* — 이 델타가 충분한지 판단 요청.
