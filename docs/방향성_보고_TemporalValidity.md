# Temporal Validity in RAG — 방향성 보고 (파일럿)

> **핵심 한 줄**: RAG에 같은 사실의 옛/새 버전이 섞이면 모델의 시점 grounding이 무너질 수 있는데(틀린 시점 문서 인용·사용), **표준 인용평가(ALCE/CitePrec)는 그 오류를 *정상*이라 판정한다(★ 맹점). 그리고 이 "충돌 견딤"은 모델 능력·크기·open여부로 *예측되지 않는 숨은 축*이다.**

작성: 2026-06-25 · 파일럿(n=48 as-of-past, 5모델)

---

## 1. 핵심 주장 (★ — 논문의 심장)

표준 RAG 인용평가 **CitePrec**(ALCE식) = *"인용 문서가 답을 뒷받침하나"* → **시점을 안 본다.**
→ 모델이 **과거 시점 질문에 *최신* 문서를 인용**해도 (답은 그 문서가 받쳐주므로) **CitePrec은 통과.**

| 충돌 시 | 우리 지표 **TV_cite** | 표준 **CitePrec** |
|---|---|---|
| 값(5모델 범위) | **0.42~0.88 (요동)** | **0.98~1.00 (전부 만점)** |
| 의미 | 시점 grounding 실패가 모델마다 다름 | *어느 모델이든 그 실패를 못 봄* ★ |

신규 지표: `TV_cite`(시점-유효 문서 인용?), `TV_behav`(답이 행동상 어느 시점에 좌우?). foil = `CitePrec`.

### CitePrec vs TV_cite — 둘 다 인용을 보지만 *묻는 게 다르다*
| | **CitePrec**(표준·ALCE) | **TV_cite**(신규) |
|---|---|---|
| 질문 | "인용 문서가 *네 답*을 받쳐주나?"(내용·시점무관) | "인용이 *맞는 시점* 문서냐?"(시점) |
| 앵커 | **모델 답**(무엇이든) → *순환* | **정답 시점 라벨** |

*예*: "2024.6 캐나다 동전 누구?"(유효답 Elizabeth II). 모델이 "Charles III"+새문서 인용 →
**CitePrec 통과**(새문서가 Charles III 받침) but **TV_cite 실패**(옛문서를 인용했어야) = ★.

### 형식화 (Formalization)
표기: 질문 *q*, as-of 시점 *t*. 검색 청크 *C* = {*c₁…c_k*}, 각 *cᵢ* = (텍스트, 타임스탬프 *τᵢ*). 시점-유효 청크 *c\** (gold), 시점-유효 정답 *a\**. 모델 답 *a*, 인용 집합 *S ⊆ C*. *c ⊨ a* = "*c*가 *a*를 뒷받침".

```
EM        = 1[ â = â* ]                         (정규화 일치)
CitePrec  = 1[ ∃ c ∈ S : c ⊨ a ]   ← 앵커 = 모델 답 a  (시점 무관)
TV_cite   = 1[ c* ∈ S ]            ← 앵커 = 정답 시점 c*
★(blind)  = { TV_cite = 0  ∧  CitePrec = 1 }
β         = P(CitePrec=1 | TV_cite=0)          (틀린시점 인용 중 표준통과율)
Δ(낙폭)   = Acc(outdated_only) − Acc(conflict),  Acc = mean 1[ a ≡ a* ]
```
- **맹점 정리**: `CitePrec = 1 ⇏ TV_cite = 1`. 경험적 **β ≈ 0.94~1.00** (틀린시점 인용 대부분이 표준통과).
- **CitePrec 순환성**: 충돌서 모델이 *c_new* 선택 → *a_new* 답 → *c_new ⊨ a_new* (자명) ⟹ **CitePrec=1, TV_cite=0.** 즉 `CitePrec ⊥ 시점유효성`.

### ★의 본질 — 충돌 시 *세 측정이 갈린다*
| 측정 | 충돌 시 | 의미 |
|---|---|---|
| **답 정확도** | **↓ 하락** | 새(틀린) 답으로 갈아탐 *(HoH도 보임)* |
| **CitePrec**(표준) | **→ 유지(~1.0)** | 틀린 답을 받치는 문서 인용 → *표준 attribution 평가는 통과* |
| **TV_cite**(우리) | **↓ 하락** | 그 인용이 *틀린 시점* 문서임을 폭로 |

→ **차별의 핵심**: *답이 틀려도 표준 인용평가(CitePrec)는 안 떨어진다(통과한다).* **HoH는 답 정확도만 봄 — 인용평가가 시점오류에 *눈멀었다*는 건 우리만의 주장.**

## 2. HoH(ACL 2025)와의 차별점

| | **HoH** (선행) | **우리** (novel) |
|---|---|---|
| 옛 정보 지위 | 오염원(현재질문·옛=오답) | **시점-유효 정답**(as-of-past·옛=정답) |
| 무엇을 잰다 | *답 정확도* 하락 | **인용-수준 시점유효성(TV) + 표준 인용평가 맹점(★)** |
| 해결 | 벤치/진단 | (목표) 시점-grounding 해결법 |

→ HoH가 *안 한 것* = **"표준 *인용평가*가 틀린 시점 인용을 통과시킨다(★)" + as-of-past.** 여기가 우리 자리.

## 3. 측정 결과 — 5모델 (as-of-past n=48, 무료 결정론 채점)

| 모델 | 분류 | 무충돌 | 충돌 | **낙폭** | TV_cite | **CitePrec** | **★/48** |
|---|---|---|---|---|---|---|---|
| GPT-5.5 | frontier | 93.8% | 87.5% | 6.2%p | 0.875 | 1.000 | 6 |
| Gemini 3.1 Pro | frontier | 85.4% | 66.7% | 18.8%p | 0.667 | 0.979 | 15 |
| Mistral-Small-24B | open | 81.2% | 64.6% | 16.7%p | 0.688 | 0.979 | 15 |
| Qwen3-32B | open | 85.4% | 47.9% | 37.5%p | 0.458 | 0.979 | 25 |
| Qwen3-8B | open | 81.2% | 43.8% | 37.5%p | 0.417 | 1.000 | 28 |

### 3-1. 충돌이 *유발한* 실패 (인과 isolation)
모델은 **시점-유효 문서만 주면 잘 맞춘다(81~94%) → 무능 아님.** 새 문서가 끼면 떨어진다 = 충돌 효과.
- **Qwen3-32B: 19/48이 "옛문서만=정답인데 충돌서 새 답으로 갈아탐"** (예: 동전 Elizabeth II→Charles III, David 소속 Mets→Rangers). *행동적 recency-pull, 파싱 아티팩트 아님.*

### 3-2. 핵심 발견 — *충돌 견딤은 능력으로 예측 안 되는 숨은 축*
- ❌ **"open이라 붕괴"는 틀림**: **Mistral-24B(open)는 Gemini(frontier)만큼 견딤**(낙폭 16.7 vs 18.8, ★15=15). 큰 낙폭은 **Qwen3 특정**.
- **matched-competence 쌍** (크기 교란 차단):
  - **Gemini = Qwen3-32B** (무충돌 85.4% *동일*) → 낙폭 **18.8 vs 37.5 (2×)**
  - **Mistral = Qwen3-8B** (무충돌 81.2% *동일*) → 낙폭 **16.7 vs 37.5 (2.2×)**
  - → *같은 능력이어도* 충돌 견딤은 **모델마다 천차만별.**
- **표준평가는 *전부* 비가시**: 실패율이 6× 다른데 **CitePrec은 다 ~1.0.**

### 3-3. 대조군
current(현재가 정답) wrong-time = 0.10(Gemini) → 실패가 *과거질문에 특정* = recency성 시간 grounding 실패.

## 4. 데이터셋 & 과제 타당성 (간략)
HoH → 현실적 RAG 청크 → 무결성 정제 → 구성 정제(genuine 시간변화만) → **58**. 항목당 3조건 + 시점-유효 라벨. 질문 템플릿(LLM 아님), 채점 무료 결정론(ALCE NLI 근사).

**과제는 *공정하고 사람-풀이 가능*** — 프롬프트가 각 문서에 `[modified: τ]` 타임스탬프 + 질문에 `As of {월 년}` + 시스템지시 *"타임스탬프로 시점-유효 문서를 골라 답하라"* 를 *모두* 준다. 사람은 날짜만 맞추면 풀림. **그런데도 모델은 최신 문서로 끌려가 틀림** → 실패가 *정보부족·과제모호가 아니라* **명시적 시점지시를 이기는 recency-pull**. (타임스탬프를 *주는* 관대한 설정인데도 실패 = 더 striking, reviewer의 "정보 없어서 아냐?" 선제차단.)

## 5. 정직한 위치 & 연구 방향

**살아남는(단단한) 것**
- **측정 기여**: TV 지표 + ★ 맹점이 *보편*(CitePrec 어디서나 ~1.0) → 실패율 변동과 *무관하게* 성립.
- **finding**: 충돌 견딤이 *능력·크기·open여부로 예측 안 되는 독립 축* + 표준평가 비가시. (matched 쌍으로 입증)

**약해진/폐기된 것**
- "open이 붕괴" 내러티브 → Mistral이 반증. 변동은 *모델별*.

**탑티어 판정(정직)**: 측정+finding 단독 = **Findings급.** **main**까지는 ↓ 중 둘 이상 필요:
1. **해결법(시점-grounding)** — 취약 모델 낙폭을 메우고 *여러 모델에 일반화* (main의 정석).
2. **폭·깊이** — 모델·조건(distractor·sharp·격차)·큰 n.
3. **프레임 확장** — "temporal"→**"RAG attribution 평가의 근본 맹점"**(인용이 답을 받쳐도 *부적합 근거*일 수 있다). 천장↑.

**연구 방향(권고)**
- **단기**: 벤치 확장(수백·어려운 조건) + 측정/변동 finding 굳히기 → 교수님과 *Findings vs main* 결정.
- **main 노리면**: 해결법 = *충돌 하에서 시점-유효 문서를 고르게* 만드는 법(시점-유효구간 grounding) → 취약 모델서 낙폭 회복 입증.
- **프레임**: attribution-faithfulness 맹점으로 일반화(temporal은 그 첫 사례).

**교수님께**: *"★(표준 인용평가가 틀린시점 인용을 통과)이 핵심 novelty(HoH와 차별). 충돌 견딤은 능력으로 예측 안 되는 숨은 축. main까지는 해결법+폭 필요한 go/no-go 파일럿."*
