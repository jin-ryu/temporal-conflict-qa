# 시간충돌 데이터셋 조사 정리 (명시적 배타 시점 충돌)

작성: 2026-07-04 · 갱신: 2026-07-05 (v3 반영) · 진단/완화용 데이터셋 적합성 전수 조사

> **용어(v3 정렬):** 기존 "sharp/hard" = **명시적 충돌**(explicit, 문서 간 배타적 상충), 기존 "soft" = **암시적 시점 중의성**(implicit, 단일 누적 문서 내). 진단·인용 기여는 **명시적**에 국한, **암시적**은 경계 대조로만 사용.

## 한 줄 결론

**깨끗한 "명시적 배타 시점 충돌" 데이터셋은 사실상 거의 없다.** 이 희소성 자체가 논문의 논거가 된다. 현재 `HoH(명시적·통제) + rag_conflicts(명시적·야생)`가 진단 코어이며, **TQA는 hard로는 부적합하나 v3에서 암시적 경계 대조군으로 채택**(266건). 추가 검토 가치가 있는 것은 **CLARK-News/ERASE**(뉴스·저유사·평가전용) 정도다.

## 적합성 판정 기준

우리 진단(mis-attribution)은 아래를 **모두** 요구한다:

1. **배타적 sharp 충돌** — 옛 문서엔 옛 답만, 새 문서엔 새 답만. 서로 모순.
2. **검색 문맥형** — 한 컨텍스트에 복수 문서(옛+새)가 공존.
3. **진짜 시간 변화** — "한때 참이었다가 대체됨"(misinfo/counterfactual/모호성 아님).

**대표 탈락 사유 3종:**
- **soft(누적 스냅샷)** — 위키 시점 스냅샷은 누적적이라 새 문서가 옛 답도 포함(예: 2014 Dida 문서 = "AC Milan 2000~2010 *그리고* Internacional 2014"). 배타성 붕괴.
- **triples-only** — 사실 트리플만 있고 문서 지문이 없음(직접 텍스트 합성 필요).
- **not-temporal** — 충돌이 misinfo/counterfactual/동명이인 모호성이라 시간축 없음.

## 논문 활용 (핵심 프레이밍, v3)

> 기존 지식충돌 벤치는 **misinfo/counterfactual/모호성**이라 "한때 참이었다가 대체된" 진짜 시점 충돌을 못 담고, 위키 스냅샷 시간QA는 **누적(암시적)**이라 배타성이 없다. **저유사 + 배타적 명시 충돌 + 대규모를 동시에 만족하는 기성 데이터는 존재하지 않는다.** 따라서 본 연구는 데이터 구축을 목표로 삼지 않고, **있는 데이터로 진단·지표·경량 완화**에 집중한다: **HoH(명시·통제) + rag_conflicts(명시·야생)**로 오귀속을 진단하고, **TQA(암시적 266건)**를 경계 대조군으로 써 오귀속이 문서 간 특유임을 확증한다. rag_conflicts n=51의 소규모는 게으름이 아니라 **깨끗한 야생 명시 시점 충돌 데이터의 원천적 희소성**을 반영하며, 이 희소성 자체가 한계이자 논거다.

**자동 분류 선례:** 명시적/암시적 분류는 Contradiction Detection in RAG(arXiv:2504.00180, 탐지·유형·분할)와 TempAmbiQA(2409.17046, 답 등가 판정)를 근거로 구현하며, 200건 인간 검수 κ로 검증한다.
