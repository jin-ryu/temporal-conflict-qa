# RAG 인용의 시점 정확성 평가 — 실험 종합 (발표/슬라이드용)

작성: 2026-06-29 · exp03(통제) + exp04(현실) 종합

> **한 줄 메시지**: AI가 검색해서 답할 때, 검색결과에 모순되는 정보가 섞이면 — **AI가 *틀린 답*을 해도, 표준 인용평가(CitePrec)는 81~100% 확률로 "근거 잘 댔다"고 통과시킨다.** 사용자는 인용을 보고 *틀린 답을 신뢰*하게 된다. 인용 평가에 *"답이 맞았나"는 잣대*가 빠져 있다. (시간 충돌이 이를 *깨끗하게 측정 가능한* 대표 무대.)

## 2. 원본 데이터셋 가공 방법

### 실험 A (HoH) — 사람이 검수하는 4단계 (AI 생성 없이 기계적으로)

**1단계 — 문서를 검색 단위로 쪼갬**
- 위키 원문을 **문장 5개 단위, 3문장씩 겹치며(슬라이딩 윈도우)** 조각(청크)으로 분할.
- 한 사건 묶음 = *옛 버전 조각* 1개 + *새 버전 전체 조각* + *관련 없는 조각(함정)*, **최대 10개**로 구성 (초과 시 함정부터 줄임).

**2단계 — 기계적으로 거를 수 있는 불량 제거** (599건 → 152건)
- *답↔근거 불일치*: 정답의 핵심 단어가 근거 문서에 실제로 없으면 제거.
- *채점 애매한 답*: 5단어 초과, 측정단위 포함(kg·lbs 등), 2자리+ 숫자 토큰(연도·체중·카운트), 숫자 비율 15% 초과 → 제거 (예: "440 lbs", "350").
- *편집 다툼*: 한 사실이 한 번에 여러 값으로 바뀐 것(단일 전환 아님) 제거.
- *유사 중복*: 옛/새 답이 사실상 같으면(정식명↔약칭) 제거.

**3단계 — 사람이 "진짜 변한 것"만 골라냄** (핵심, 152건 → 219건)
- **채택 기준 = "시간이 지나며 진짜로 바뀌는 속성"**: 현직자(시장·MP·장관·코치·교장), 선수 소속팀, 회사 소유주, 챔피언, 기관·경기장·도시 *개명*, 리그 승강, 선거 결과, 스폰서 변경.
- **제외 기준 = "시간과 무관한 사실"**: 고대사·역사적 사건, 출생지·국적 등 전기 고정사실, 학명 재분류, 신화·소설 줄거리, 단순 집계 오류 (→ 이런 건 "그 시점의 정답"이란 게 성립 안 함).
- 판단법: *"옛 답이 그 옛 시점엔 진짜로 맞았나?"* — 맞으면 채택(genuine), 아니면(그냥 정정) 제외.

**4단계 — 질문에 시점을 명시**
- 원래 질문 앞에 "As of 2024-09, …"처럼 *어느 시점을 묻는지* 붙임 (AI 생성 아닌 정해진 양식).

> 역할 구분: 실험 A는 *시점을 명시한* 통제 질문(과거 180 + 현재 대조 39). **완전한 현재지향(시점 안 정함)은 실험 B(rag_conflicts)가 담당** — A의 원본 질문을 시점 없이 쓰면 정답이 모호해 채점이 깨끗하지 않기 때문.

### 실험 B (rag_conflicts) — 손대지 않고 그대로

**1단계** — Google이 수집한 실제 검색결과 458건 중, "오래된 정보 때문에 충돌(Conflict due to outdated information)" 유형 **62건**만 선택.

**2단계** — 변형 없이 우리 형식으로: 검색결과 = 문서 조각(텍스트+수집날짜), 질문 = 원래 그대로, 정답 = correct_answer(최신값).

**3단계** — 충돌이 성립하는 것만 필터: *정답(최신) 담은 문서 1개 이상* + *옛(outdated) 문서 1개 이상* 둘 다 있어야 채택 → **51건**.

- *질문을 인위적으로 바꾸지 않음.* 검색 노이즈(CAPTCHA·에러 페이지 등)도 *현실 그대로* 둠.

### 실험 C (ConflictBank) — 3유형 충돌을 유형별로 분리

**1단계** — 한 항목엔 정답 evidence + **3유형 충돌 evidence**(오정보·시간·의미)가 다 들어있음. 4,000건 스캔.

**2단계** — 유형마다 별도 문항: [정답 evidence] + [그 유형의 충돌 evidence] + [다른 항목 evidence 2개=함정].

**3단계** — 유형당 40건 → **120건** (오정보 40 + 시간 40 + 의미 40). 정답 = correct_option.

- ⚠️ **합성**: evidence가 AI 생성(소설체), 시간 충돌이 미래 날짜(2026~) 등 → *통제·일반화 보조용*. 현실성은 A·B가 담당.

## 3. 데이터셋 예시 (실제 JSON 구조)

각 문항은 아래 JSON 형식. `chunks`의 `label`: `outdated`(옛)/`current`(새·정답)/`distractor`(함정), `last_modified_time`(문서 시점), `evidence_chunk_id`(시점-유효 정답 문서).

### 실험 A 예시 — "LA 시의회 President pro Tempore" (충돌 219건 중 1건)
```json
{
  "id": "hoh_74_outdated_0",
  "new_question": "As of September 2024, who is the current President pro Tempore
                   of the Los Angeles City Council?",
  "target_answer": "Marqueece Harris-Dawson",          // 9월 시점 정답 ✓
  "evidence_chunk_id": 23,                              // 이 문서를 인용해야 맞음
  "chunks": [
    {"chunk_id": 23, "label": "outdated",  "last_modified_time": "2024-09-01",
     "text": "...President pro Tempore is Marqueece Harris-Dawson..."},   // 옛(정답)
    {"chunk_id": 1,  "label": "current",   "last_modified_time": "2024-10-01",
     "text": "...President pro Tempore is Bob Blumenfield..."},          // 새(오답 유발)
    {"chunk_id": 2,  "label": "distractor","last_modified_time": "2024-10-01",
     "text": "As a nonpartisan council, the City Council does not..."}   // 함정
    // ... 총 10개
  ]
}
```
*(번역)* "2024년 9월 기준 LA 시의회 President pro Tempore는?" → **정답 Marqueece Harris-Dawson**(9월 문서). AI가 새 문서(Bob Blumenfield)로 끌리면 → 시점 틀린 인용 ★.
- 전체: **충돌 219건**, 각각 옛 답↔새 답 명확히 다름, 문서 평균 10개.

### 실험 B 예시 — "FBI 국장" (충돌 51건 중 1건)
```json
{
  "id": "rc_2_current",
  "new_question": "who is the director of the fbi",     // 시점 안 정한 자연 질문
  "target_answer": "Kash Patel",                        // 최신 정답 ✓
  "chunks": [
    {"chunk_id": 0, "label": "outdated",    "last_modified_time": "2016-05-03",
     "text": "Directors, Then and Now ..."},                // 옛 명단
    {"chunk_id": 1, "label": "current_dup", "last_modified_time": "2016-06-13",
     "text": "The current Director is Kash Patel ..."},      // 정답 담았으나 옛 시점
    {"chunk_id": 2, "label": "current",     "last_modified_time": "2025-03-11",
     "text": "Director Kash Patel ... (BBC 2025)"}           // 최신·정답
    // ... 총 9개 (2016~2025 뒤섞임, CAPTCHA 에러 페이지 등 노이즈 포함)
  ]
}
```
*(번역)* "FBI 국장은?" → **정답 Kash Patel**(최신). AI가 옛 국장 담긴 문서에 속으면 → 시점 틀린 인용 ★.
- 전체: **충돌 51건**, 2~10년 시차 문서 뒤섞인 실제 웹, 문서 평균 9개.

### 실험 C 예시 — "Nära dig 연관 인물" (오정보 충돌, 120건 중 1건)
```json
{
  "id": "cb_misinformation_0",
  "conflict_type": "misinformation",
  "new_question": "Which role or musical work is Nära dig associated with as a performer?",
  "target_answer": "Kikki Danielsson",                  // 정답
  "chunks": [
    {"chunk_id": .., "label": "current",
     "text": "...Musical Legacy of Kikki Danielsson..."},     // 정답 evidence
    {"chunk_id": .., "label": "outdated",
     "text": "...Susan Boyle... (오정보로 바꿔치기)"},          // 충돌(오답 유발)
    {"chunk_id": .., "label": "distractor", "text": "..."}     // 함정(다른 항목)
  ]
}
```
*(번역)* "Nära dig는 누구?" → **정답 Kikki Danielsson**. AI가 오정보 문서(Susan Boyle)에 속으면 → 틀린 인용 ★.
- 전체: **충돌 120건** (오정보·시간·의미 각 40), 합성. *시간 외 충돌에서도 mis-attribution 생기나* 검증용.

## 4. 각 가공 데이터셋이 의미하는 바

| | 실험 A (HoH) | 실험 B (rag_conflicts) | 실험 C (ConflictBank) |
|---|---|---|---|
| **충돌 종류** | 시간 | 시간 | 시간+오정보+의미 |
| **질문 방향** | 과거 시점 묻기 | 현재 묻기 | 사실 묻기 |
| **AI의 실패 방향** | 과거 물음 → *최신*에 끌림 | 현재 물음 → *옛것*에 속음 | 충돌 문서에 속음 |
| **난이도** | 통제됨 (깨끗) | 자연스러움 (노이즈) | 대규모·합성 |
| **역할** | **통제된 증명** | **현실 검증** (ecological) | **충돌유형 일반화** |

→ **세 실험이 상보적**: 실험실(A)에서 깨끗하게 증명, 야생(B)에서도 일어남 확인, 다유형(C)으로 *시간 외에도* 일반화. **충돌은 양방향·다유형 모두 AI를 실패시킨다.**

> 참고: 실험 A에는 "과거 시점 질문" 180건 외에, **"현재 시점 질문" 39건도 대조군**으로 포함. → 과거 질문은 30% 틀리는데 현재 질문은 10%만 틀림 = *실패가 특히 "과거를 물을 때" 심함*을 보여줌.

## 5. 실험 방법

### 5-0. 실험 규모 요약

| | A: HoH | B: rag_conflicts | C: ConflictBank |
|---|---|---|---|
| 출처 | 위키 편집이력 | Google 웹검색 | NeurIPS24 합성 |
| 충돌 | 시간(통제) | 시간(현실) | 시간+오정보+의미 |
| 평가 문항 | 219 (과거180+현재39) | 51 | 120 (유형당40) |
| 모델 | 5종 | 5종 | 3 오픈 |
| 채점 | 무료 결정론 (eval_unified.py 통일, 유료 심판 미사용→재현가능) | 동일 | 동일 |
| 분석 | mis-attr, faithfulness, 위치 ablation, 지표 일반성 | mis-attr, faithfulness | mis-attr, faithfulness |

> 5종 = GPT-5.5 · Gemini 3.1 Pro · Qwen3-32B · Qwen3-8B · Mistral-Small-24B. C는 합성·보조라 frontier 스킵.

### 5-1. 기본 구조 (모든 실험 공통) — AI에게 주는 프롬프트

**시스템 지시:**
> "문서들에는 각각 번호와 *수정 날짜(타임스탬프)* 가 붙어 있다. **날짜를 보고 질문이 가리키는 시점에 유효한 문서를 골라** 그 문서를 근거로 답하라. 인용은 [번호]로 표시. `<reasoning> 어느 문서가 시점에 맞는지 간단 추론 </reasoning> <answer> 짧은 답 [번호] </answer>` 형식으로만 출력."

**사용자 메시지 예:**
```
[Query] 2024년 9월 기준, 현재 LA 시의회 의장은?
[Document 1] [수정일: 2024-10-01]  ...현재 의장은 Marqueece Harris-Dawson...
[Document 2] [수정일: 2024-09-01]  ...현재 의장은 Paul Krekorian...
[Document 3] [수정일: 2024-10-01]  (관련 없는 문서)
...
```
- **인용을 [번호]로 다는 방식 = ALCE(표준 RAG 인용평가)와 동일.**
- 시점 단서(타임스탬프)와 시점 지시를 *모두 주는* 관대한 조건 → 그래도 틀리면 진짜 실패.
- 채점은 **무료 결정론적 방법**(유료 LLM 심판 없음) → 누구나 재현 가능.

### 5-2. 평가 지표 — 기존의 함정과 우리 지표 (수식)

**① 정답 채점 — EM**

$$\text{EM} = \mathbb{1}\big[\ \hat{a} = a^{*}\ \big]$$

- $\hat{a}$ = AI 답, $a^{*}$ = 정답. "답이 맞았나" (의미매칭).

**② 기존 표준 인용 지표 — CitePrec (ALCE)**

$$\text{CitePrec} = \mathbb{1}\big[\ \exists\, c \in S : c \models \hat{a}\ \big]$$

- $S$ = AI가 인용한 문서들, $c \models \hat{a}$ = "문서 $c$가 *AI 답* $\hat{a}$를 뒷받침".
- 즉 **"인용한 문서가 *내 답*을 받쳐주나?"**
- ⚠️ **결정적 함정 (순환성)**: 앵커가 *AI 자신의 답* $\hat{a}$ → **AI가 *틀린 답*을 내고 *그 틀린 답을 담은 문서*를 인용하면 자동으로 통과.**

$$\boxed{\ \text{EM}=0 \ \wedge\ \text{CitePrec}=1\ \text{ 가능}\ }$$

> *틀린 답인데, 표준 인용평가는 "근거 잘 댔다"고 통과* → 사용자가 *틀린 답을 인용 보고 신뢰.*

**③ 우리 헤드라인 지표 — mis-attribution (★)**

$$\bigstar = \{\ \text{EM}=0 \ \wedge\ \text{CitePrec}=1\ \}, \qquad
\text{mis-attr} = P(\text{CitePrec}=1 \mid \text{EM}=0)$$

- **★** = "답은 틀렸는데 표준 인용평가는 통과시킨 칸" = *우리가 찾는 사각지대.*
- **mis-attr** = *틀린 답 중* 표준 인용평가가 놓친 비율 (높을수록 인용평가가 눈멈).
- → *"시점" 개념 없이* 누구나 이해 + EM(정답)을 *재료로* 써서 중복 없음. **충돌 유형 불문 적용 가능** (정답·인용 내용만 필요, 정답청크 라벨 불필요).

**④ faithfulness 분류 — 틀린 인용이 *진짜* 사용인가**

문서제거 counterfactual: 틀린 답이 *단일조건(옛만/새만)* 답과 일치하면 그 문서에 *행동 의존* = **faithful-wrong**(진짜 보고 틀림), 아니면 **post-rat**(사후 인용).

> 기존 평가축 비교: **correctness**(ALCE, 답 받치나) · **faithfulness**(Wallat 2025, 진짜 썼나) — 둘 다 *"틀린 답×좋은 인용"* 의 괴리를 직접 측정 안 함. (보조 지표) TV_cite = 인용이 *시점-유효 문서*인가(시간 충돌 특화) — mis-attr의 시간 버전.

### 5-3. 추가 분석 방법 4가지

**(가) main 실험** — mis-attribution 측정. "틀린 답에 인용평가가 통과하나?" (5모델 × 3데이터셋)

**(나) faithfulness 분류** — *문서를 빼보는 반사실(counterfactual)* (AI 재호출 없이 기존 응답으로 계산):
- 틀린 답을 했을 때, *그 충돌 문서를 빼면 답이 바뀌나?*
  - **바뀜 → faithful-wrong** (그 문서를 *진짜 보고* 답함) ← 우리 신규 범주
  - **안 바뀜 → post-rationalization** (답은 이미 알고 인용만 갖다붙임) ← Wallat 2025 범주
- 각 항목의 *옛 문서만 / 새 문서만* 조건이 이미 있어 무료로 비교.

**(다) 위치 ablation** — *정답 문서를 프롬프트 맨앞/맨뒤에 강제 배치*해 재측정 (exp03):
- "AI가 내용이 아니라 *위치(맨 뒤 문서)* 로 고르는 건 아닌가?"를 검증.

**(라) 충돌유형 일반화** — ConflictBank로 *시간 외*(오정보·의미) 충돌에서도 mis-attribution 생기나 (exp05).

## 6. 실험 결과

### 6-1. main — 기존 인용평가는 "틀린 답"을 못 잡는다 (mis-attribution)

세 실험·5모델 통일 결과 (mis-attr = 틀린 답 중 CitePrec 통과 비율):

| 실험 | 충돌 성격 | CitePrec(기존) | **mis-attribution** |
|---|---|---|---|
| **A** HoH (통제·시간) | 5모델 | 0.97~1.00 | **92~100%** |
| **B** rag_conflicts (현실·시간) | 5모델 | 0.86~0.94 | **81~93%** |
| **C** ConflictBank (다유형) | 3오픈 | 1.00 | **100%** |

**읽는 법:**
- **기존 지표(CitePrec) 0.86~1.00 = 거의 만점** → 표준 평가로는 "인용 잘함".
- **그런데 mis-attribution 81~100% = 틀린 답의 대부분을 기존 지표가 "정상 인용"으로 통과** ← ★ 핵심.
- **최강 GPT조차** exp03서 mis-attr 100% (틀린 답 35건 *전부* CitePrec 통과). (다른 표준 지표 CiteRecall·AIS도 동일.)

### 6-2. faithfulness 분류 — "진짜 보고 틀렸다" (Wallat과 구별)

틀린 인용 중 *faithful-wrong*(충돌 문서를 진짜 사용해 틀림) 비율:

| | A (통제) | B (현실) | C (다유형) |
|---|---|---|---|
| faithful-wrong | **63~81%** | **43~57%** | **87~93%** |

- → 세 실험 모두 **상당수가 "문서를 진짜 보고 따라가서" 틀림** (대충 갖다붙인 post-rat 아님).
- → Wallat 2025의 post-rationalization과 **구별되는 새 실패 유형**, 통제·현실·다유형 전반서 재현.

### 6-1b. 충돌유형 일반화 (exp05) — 시간 외에도

ConflictBank 3유형 × 3모델 = 9개 조합 **전부 mis-attribution 100%**:

| 모델 | misinformation | temporal | semantic |
|---|---|---|---|
| Qwen3-8B / 32B / Mistral | 100% | 100% | 100% |

→ **mis-attribution은 시간 충돌 특유가 아니라 *충돌 일반*의 문제** (오정보·의미서도 동일). *(합성 데이터라 100% 포화 — 현실 수치는 exp03/04가 신뢰.)*

### 6-3. 위치 ablation — 메커니즘은 "위치 편향 + 시점 추론 실패"의 혼합

정답 문서를 맨앞 vs 맨뒤에 둘 때 시점 정확 인용율 변화 (Δ):

| 모델 | 맨앞 | 맨뒤 | Δ |
|---|---|---|---|
| Mistral-24B | 0.43 | 0.84 | **−0.41** (위치 영향 큼) |
| Qwen3-32B | 0.55 | 0.73 | −0.18 (중간) |
| Qwen3-8B | 0.56 | 0.63 | −0.07 (거의 없음) |

- → AI는 *맨 뒤 문서를 선호*하는 위치 편향이 있으나 **모델마다 다름.**
- → 충돌 실패는 *위치만으로 설명 안 됨* (Qwen은 위치 영향 −18%인데 실패는 더 큼) = **위치 편향 + 진짜 시점추론 실패의 혼합.**

## 7. 해석 — 기존 지표가 못 찾은 문제를 찾음

### 우리가 찾은 것 = "인용 평가의 맹점 (mis-attribution ★)"
- **표준 인용평가(ALCE의 CitePrec)는 *AI 답*을 앵커로 삼아 순환한다** → AI가 틀린 답을 내고 그 답을 담은 문서를 인용하면 통과.
- 따라서 *틀린 답이어도* "인용 잘함" 정상 판정 → **사용자도, 평가지표도 속는다.**
- 우리 헤드라인 지표 **mis-attribution**(틀린 답 중 CitePrec 통과 비율)이 이 빠진 잣대를 드러냄.

### 핵심 발견 5가지
1. **mis-attribution은 보편적**: 5모델·3데이터셋 모두 81~100%. **최강 GPT조차** 틀린 답을 거의 다 "잘 인용"으로 통과.
2. **충돌유형 불문**(exp05): 시간뿐 아니라 오정보·의미 충돌서도 100% → *충돌 일반*의 문제.
3. **양방향 실패** (최신 편향의 대칭): 과거 질문 → *최신*에 끌림 / 현재 질문 → *옛것*에 속음 → 둘 다 기존 지표가 비가시.
4. **faithful-wrong**(우리 고유): 틀린 인용의 43~93%가 *진짜 그 문서를 보고* 틀림 → Wallat 2025의 post-rationalization과 구별, 세 실험서 재현.
5. **통제 + 현실 + 다유형 모두 입증**: 실험실(A)·실제 웹(B)·다유형(C) 전반 → 인위적 현상 아님.

### 학술적 위치 — 인용평가의 빠진 연결고리

| 평가 축 | 묻는 질문 | 선행연구 |
|---|---|---|
| correctness (인용) | 인용이 *AI 답*을 뒷받침하나 | ALCE (2023) |
| faithfulness | 인용을 *진짜 썼나* | Wallat (2025) |
| **★ mis-attribution** | 인용평가가 *틀린 답*도 통과시키나 (답정확성×인용 연계) | **본 연구 (빈칸)** |

- 가장 가까운 Verified Misguidance(2025)도 *"answer-correctness link는 future work"* 로 명시 → 우리가 그 빈칸을 메움.
- 우리 실패는 *correct(답 받침)·faithful(진짜 사용)인데 답이 틀림* → 기존 축으로 설명 안 됨. **충돌 일반에서 측정 가능**(시간 충돌이 대표 무대).

### 실제 임팩트 (왜 중요한가)
- **법률**: 소급적용 금지 — 사건 시점의 법령을 인용해야 (틀린 버전 = 법적 오류).
- **금융/감사**: 특정 시점 기준 정확성이 규제 의무.
- **의료**: 옛 지침을 현행처럼 인용 = 환자 위해.
→ 고위험 도메인에서 *틀린 버전 인용*을 현 평가가 못 걸러냄.
